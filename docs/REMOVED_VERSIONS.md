# Removed versions

Why older downloads, tags and branches are no longer on GitHub.

## Every version before 3.0.0

Removed because they don't follow [Grinding Gear Games' third-party policy](https://www.pathofexile.com/developer/docs#policy):
*"Reading from the screen or clipboard may only be performed once per manual key press."*
Versions before 3.0.0 read the screen by themselves (on a timer) for some helpers. 3.0.0 and newer read the screen or clipboard only once per key press you make; see [TOS.md](../TOS.md).

| When | What | How |
|---|---|---|
| 2026-11-16 | 98 releases before 3.0.0, and their tags | Actions › Purge old releases |
| 2026-11-16 | The last 2.x branches (`v2.133.0-active`, `v2.133.1`, `v2.137.1`, `v2.138.0`, `v2.143.0`) and 22 `archive/*` tags | Actions › Remove old versions |

Please don't run a version older than 3.0.0 with the game.

## 3.0.2 (preview)

The 3.0.2 and 3.0.2-linux-preview test builds were removed on 2026-11-16, never released: What's new would not close (issue #278). Everything in 3.0.2 is in 3.0.3.

## Previews

From 3.0.3 there are no preview releases: each version is tested on a local build first, then published as a full release.
